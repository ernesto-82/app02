# Ejercicios IAW - App02

Aplicación web con 6 ejercicios básicos de PHP, usando una arquitectura separada en Frontend, Backend y Librería de funciones.

## Ejercicios

1. **Saludo Personalizado** - Uso de `$_GET`.
2. **Tabla de Multiplicar** - Uso de bucles y `$_GET`.
3. **Contador de Vocales** - Recorrido de strings con `for`.
4. **Cálculo de Edad** - Uso de `$_POST` y `date()`.
5. **Lista de la Compra** - Uso de arrays y sesiones (`$_SESSION`).
6. **Adivina el Número** - Combinación de sesiones y lógica.

## Estructura

- `index.html`: Menú principal.
- `pags/ejerciciosIA/`: Los 6 archivos visuales (Frontend).
- `PHP/`: Los archivos de procesamiento (Backend).
- `PHP/includes/libreria.php`: Funciones compartidas.

## Cómo ejecutarlo

Servir la carpeta con Nginx (localhost:8091) y abrir `index.html`.
